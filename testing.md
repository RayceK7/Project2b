# Testing
I tested the dataset generator and Merge Sort to make sure they work correctly.
## Dataset Generator
I tested four types of datasets: random, sorted, reverse-sorted, and duplicates.
I used 100,000 and 250,000 values for the performance tests.
## Merge Sort
I tested Merge Sort with different datasets to check if it sorted the numbers correctly.
I also tested empty lists, small lists, and lists with duplicate numbers.
All 7 automated tests passed.
## Performance
I measured the execution time and number of comparisons for Merge Sort.
All 8 benchmark runs sorted the data correctly.
The results are saved in merge_sort_results.csv.
## Conclusion
Merge Sort worked correctly with all the datasets tested. Larger datasets generally took longer to sort.
